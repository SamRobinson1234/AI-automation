# Antarctic Weather

A local dashboard for hourly temperatures, wind speeds, and playful penguin suggestions at four representative Antarctic stations:

| Region | Station |
| --- | --- |
| North Antarctica | Esperanza Base |
| East Antarctica | Davis Station |
| South Antarctica | Amundsen–Scott South Pole Station |
| West Antarctica | Rothera Research Station |

Select a station, date, and local hour for the single-location forecast. The dashboard shows the rolling 168-hour forecast; the server caches each station's response for 55 minutes.

## Journey planner

Select start and end stations and a departure time, then enter waddling and swimming distances. The estimated duration uses editable speeds, defaulting to 2.5 km/h waddling and 8 km/h swimming. The straight-line station distance is shown for reference, but the entered distances determine the journey estimate. Hourly journey advice is based on the start station's forecast only, not route-wide weather. Hours outside the seven-day forecast are clearly marked unavailable.

## Run

1. Install Python 3 and connect to the internet.
2. Open a terminal in this directory and run `python main.py`.
3. Open <http://127.0.0.1:8765> if the dashboard does not open automatically.

Keep the terminal open while using the app; press Ctrl+C to stop the server. Forecasts come from [Open-Meteo](https://open-meteo.com/) and require no API key.

## Project files

- `main.py` serves the dashboard and station/forecast API, and caches forecast responses.
- `dashboard.html` contains the accessible page structure.
- `styles.css` contains layout and responsive styles.
- `app.js` handles station loading, forecast selection, advice, and journey calculations.

The **Local vibes** illustration is inline SVG, generated by the browser. When wind exceeds 10 mph, below-zero temperatures suggest a huddle and above-zero temperatures suggest suncream and avoiding umbrellas. At 10 mph or less, below zero suggests a coat and above zero suggests hitting the beach; exactly zero degrees gets a neutral suggestion. This is playful, not wildlife guidance: observe wild penguins from a respectful distance and do not dress, handle, or apply products to them.
